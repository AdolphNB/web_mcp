常见问题

工具目录中的每个工具都能直接运行吗？

目录提供工具信息。是否可以运行、调用地址与参数，以该工具说明和 API 文档为准。

遇到接口问题怎么办？

请将接口路径、错误信息和复现步骤发送至 304633698@qq.com，请勿附带密钥。

如何通过 Agent 管理网站？

站点所有者可配置管理接口，通过 MCP 桥接程序查询访问量和编辑新闻。此功能需要独立的管理凭据，详细部署步骤见项目中的 HERMES_SETUP.md。
