# 奇点临近品牌资源

本版采用「汇聚」意象：开放的轨道围绕中心点，代表工具、系统与 AI 的连接。

- `brand-mark.svg`：透明底主标志，64 × 64 画布；导航、页脚使用。建议显示尺寸不小于 32px，周围保留至少 8px 空白。
- `favicon.svg`：带深色底的浏览器图标，浅色或深色浏览器主题均可识别。
- `apple-touch-icon.png`：180 × 180 的触屏快捷方式图标，由 favicon 矢量稿导出。
- `brand-orbit.svg`：首页装饰图，不代表实际系统状态或产品运行数据。
- `brand-social.svg` / `brand-social.png`：1200 × 630 分享卡片，PNG 用于 Open Graph / Twitter 元信息；SVG 保留可编辑源稿。
- `log.png` 与 `log_original_backup.png` 为旧资源备份，不再在页面中引用。

品牌色：背景 `#0B141B`，面板 `#111E27`，正文 `#E8F0F3`，强调色 `#54D6C7`。标志搭配中文名称与英文 `SINGULARITY NEAR` 使用，不把长公司全称压缩到图标中。页面使用本机字体，不加载第三方字体服务。

SVG 没有脚本或外部资源依赖。PNG 使用 Sharp 从 SVG 导出，修改矢量稿后需同步导出。分享图与图标更换文件内容时，应更新 URL 版本或文件名以刷新缓存。
